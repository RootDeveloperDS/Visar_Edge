# VISAR Edge Public

This repository contains the public release, documentation, and tools for VISAR Edge.

## Structure

- `releases/` — Release metadata and versioned release files
- `assets/` — Release and global assets
- `docs/` — Documentation and changelogs
- `schema/` — JSON schemas and validators
- `tools/` — Release generator and CI tools
- `public-api/` — Public API endpoints (auto-generated)
- `.github/` — GitHub workflows and issue templates

See `docs/overview.md` for more details.
